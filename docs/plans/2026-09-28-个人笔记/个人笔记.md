## Overview

**Goal:** 按需求文档从零实现「个人笔记」Web 应用：Flask + SQLite 后端提供 REST JSON API，原生 HTML/CSS/JS 多页面前端，覆盖账号、笔记写作与发布、Markdown 渲染、分享、评论、收藏、个人主页，以及划词右键 AI 润色。

**Architecture:** Flask 应用工厂 + 蓝图；页面路由只输出 HTML 骨架，`/api/*` 返回统一 `{code, message, data}`；业务规则集中在 `services/`，数据访问经 Flask-SQLAlchemy；前端所有请求经 `static/js/api.js` 单一出口，`code != "OK"` 时只展示后端 `message`。Markdown 由前端 marked.js 渲染 + DOMPurify 消毒，预览与详情页共用同一渲染函数。

**Tech Stack:** Python 3.12.7 · Flask 3.1.3 · Werkzeug 3.1.9 · Flask-SQLAlchemy 3.1.1 · SQLAlchemy 2.0.54 · Flask-Login 0.6.3 · requests 2.32.5 · pytest 8.4.2（仅测试） · marked 18.0.14 · DOMPurify 3.4.16（本地 vendor）

## Assumptions and Dependencies

- **运行环境**：本机 Python 3.12.7、pip 24.2 可用；项目目录不在版本控制下（无需 git 相关步骤）。
- **依赖来源**：PyPI 用清华镜像 `https://pypi.tuna.tsinghua.edu.cn/simple`；前端库用 jsdelivr 固定版本下载后本地引入。
- **数据库**：SQLite，首次启动 `db.create_all()` 建表，无迁移工具；如模型变更，删除 `instance/notes.db` 重建（本地应用，无历史数据）。
- **会话**：Flask 签名 Cookie + Flask-Login，会话级（关浏览器失效）；`HttpOnly` + `SameSite=Lax`。
- **CSRF**：写接口要求 `Content-Type: application/json`（非 JSON 直接 `PARAM_ERROR`），配合 `SameSite=Lax` 阻断跨站表单提交。
- **HTTP 状态码**：业务错误统一 200，前端只按 `code` 分支（避免两套判断源）。
- **AI 可用性**：未配置 `AI_API_KEY` 时自动回退本地模拟，功能不中断。
- **图片素材**：`图片素材/个人笔记主页.jpg` 与 `图片素材/个人笔记-笔记背景.jpg` 已存在，复制到 `static/img/`。
- **视觉细节核对**：计划作者未能读取图片内容，需求文档中"木桌静物照 / 羊皮纸花角羽毛笔罗盘"等描述来自文件名推断，**必须在 Phase 5 与 `项目截图/` 逐张人工核对并修正**。

## Deferred Decisions

以下为非阻塞项，实现时按默认处理，确认后可直接调整：

1. **主页"云端同步"文案**：Phase 5 处理口径——标题保留截图原文「云端同步」，说明文案改为本地数据库口径（「笔记统一保存在本机数据库中，随时打开继续写」），以满足需求文档 F3「不得出现与实现不符的承诺」；是否把标题也改成「本地存储」**待 master 最终确认**。理由：纯文案，不影响实现。
2. **个人信息可编辑**：默认只读展示用户名、邮箱、注册时间。理由：需求文档 Deferred #3 已定默认。
3. **AI 默认模型**：`AI_BASE_URL` 默认 `https://api.deepseek.com/v1`，`AI_MODEL` 默认 `deepseek-chat`，`AI_API_KEY` 默认空（走模拟）。理由：OpenAI 兼容协议，换供应商只需改配置。
4. **模拟润色算法**：默认确定性规则改写（用词替换 + 标点与空格规范化 + 代码块与 Markdown 标记跳过），不做随机。理由：需求文档 Deferred #6 已定默认。
5. **笔记标题允许重复**：默认允许。理由：需求文档 Deferred #7 已定默认。
6. **标签不做独立管理页**：默认从用户已有笔记聚合。理由：需求文档 Deferred #8 已定默认。
7. **marked 换行行为**：默认 `breaks: true, gfm: true`（单个换行渲染为 `<br>`，符合中文写作直觉）。理由：两选项皆可，选更贴合笔记场景的一个。
8. **数据库变更处理**：模型调整时删库重建，不引入迁移工具。理由：本地应用、无历史数据。
