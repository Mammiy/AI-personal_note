## Task 2: 响应式与无障碍核对

**Goal:** 满足需求文档「响应式规则」「Accessibility」两节的全部条目。

**Files:**
- Modify（仅在发现偏差时）: `static/css/base.css`、`static/css/pages.css`、各模板

**Steps:**

- [ ] 按三档视口逐页检查：1440（基准）、768–1023（工具栏与预览换行、Hero 上下排列）、≤767（多列区域纵向堆叠、导航紧凑行）
  - 页面：主页、注册、登录、工作台、我的文章、写笔记、笔记详情、分享页、个人主页、AI 弹窗
  - Expected: 每档都无横向滚动条、无元素溢出卡片、无重叠
- [ ] 语义结构：每页唯一 `<h1>`；`header/nav/main/footer` 齐全；表单控件有 `<label for>`；交互元素为 `<button>`/`<a>`
- [ ] 键盘可达：Tab 遍历全部交互元素；右键菜单可 `Shift+F10` 唤起、`Enter` 激活、`Esc` 关闭；AI 弹窗 `Esc` 关闭、`Tab` 在弹窗内循环、关闭后焦点回到编辑区并保留选区
- [ ] 焦点可见：所有可聚焦元素出现 2px `--gold`(#C9A96A) 外环，页面无 `outline: none`
- [ ] 对比度：正文 `--ink` 对纸色背景与白卡片、次要文字 `--ink-soft`、按钮白字对 `--brown` 逐项量测
  - Expected: 正文 ≥ 7:1，次要文字与按钮文字 ≥ 4.5:1
- [ ] 表单错误：错误态同时有 `--danger` 描边与中文文案，并用 `aria-describedby` 关联
- [ ] 触控目标：按钮与开关可点区域 ≥ 32×32px
- [ ] 图片：正文图片带 `alt`；羊皮纸底纹与花角为 CSS 背景或 `aria-hidden`，不进入无障碍树
- [ ] 动效：系统开启「减少动态效果」后，过渡与旋转全部停止

**Verification:**
- [ ] 用 DevTools 设备工具栏在 1440 / 768 / 375 三档逐页截图
  - Expected: 无横向滚动条（`document.documentElement.scrollWidth <= window.innerWidth`）
- [ ] 仅用键盘完成：注册 → 新建笔记 → 划词 → `Shift+F10` → `Enter` → `Esc`
  - Expected: 全流程可完成，每步焦点位置可见
- [ ] 开启系统「减少动态效果」后打开 AI 弹窗
  - Expected: 弹窗仍正常显示，spinner 不旋转

  - Expected: 每条都有中文提示或被正确截断，不出现 500 页面与英文堆栈
- [ ] 权限矩阵：准备用户 A、用户 B、未登录访客 C

  - C 篡改分享 token 为随机值 → 「分享已关闭」
- [ ] 把每条执行结果记入验收表；发现缺失的补进 `tests/`
